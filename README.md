# 前景フレームメーカー

ココフォリアの前景に使う「枠」画像を、ブラウザだけで作るツール。

**公開サイト: https://shiki365.github.io/foreground-frame-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

## できること

- **枠のデザイン** — 窓（見える範囲）の太さ、角の形（直角 / 丸 / 面取り / えぐり / 切り欠き）、楕円、色、塗り、線、影。ひな形 11 種
- **飾り** — 蔦・小花・茨・桜の枝・草むら・星くず・蜘蛛の巣・鎖・歯車・回路・雪とつらら・したたりを、窓のふちに沿って重ねる（配置・大きさ・密度・伸び具合・色）
- **自分の素材と文字** — 画像を重ねて配置（ドラッグ移動、合成モード、枠の上だけ / 窓の中だけに描く、色の塗り替え）。文字は縦書き・縁取り・フォントファイルの読み込み・PC に入れたフォントの指定（Chrome / Edge では一覧から見た目で選べる）に対応
- **差分（使うときだけオン）** — 時間帯・天気・季節・場面の空気・正気度・章・自由。差分ごとに色、窓の色かぶり、窓の演出（雨・雷雨・雪・霧・花びら・落ち葉・暗がり・警告・ノイズ・セピアなど）、表示を変え、ZIP でまとめて書き出す。素材や飾りも差分ごとに出し分けられる
- 元に戻す / やり直す、自動保存、プロジェクトファイルの保存と読み込み、マス目表示、プレビュー用の風景

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と CSS |
| `favicon.svg` | ブラウザのタブに出るアイコン |
| `presets.v1.js` | ひな形・差分の種類・演出・飾りの一覧など（データだけ） |
| `model.v2.js` | プロジェクトの状態（初期値、ひな形の適用、v1 のデータの移行） |
| `render.v2.js` | 枠の描画（UI に依存しない。プレビューと書き出しで同じ関数を使う） |
| `deco.v1.js` / `deco-extra.v1.js` | 枠の飾り |
| `effects.v1.js` | 窓の演出 |
| `icons.v1.js` | 差分の表示に使うアイコン |
| `app.v2.js` | UI、履歴、自動保存（IndexedDB）、書き出し |
| `zip.v1.js` | 無圧縮 ZIP の書き出し |
| `pcfonts.v1.js` | PC に入っているフォントを一覧から選ぶダイアログ（3 ツール共通のファイル） |

座標や大きさはすべて「高さ 1080 の仮想座標」で持っているため、出力サイズを変えてもデザインの比率は崩れない。

飾りは、窓の輪郭を外側にずらした線（ガイド）を一定間隔でたどり、各点の向きと「どの辺か」から描く位置を決めている。新しい飾りは `FrameDeco.TYPES` に関数を 1 つ足し、`presets.v1.js` の `DECO_TYPES` に名前を書けば増やせる。

v1（時間帯の差分だけだった版）の自動保存やプロジェクトファイルは、読み込むと「時間帯」の差分として自動で変換される。

非公式ツールであり、ココフォリアとは関係ありません。
