# 前景フレームメーカー

ココフォリアの前景に使う「枠」画像を、ブラウザだけで作るツール。

**公開サイト: https://shiki365.github.io/foreground-frame-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

## できること

- **時間帯の差分** — 朝・昼・夕・夜ごとに枠の色、アイコン、窓の色かぶりを設定し、ZIP でまとめて書き出す
- **窓（見える範囲）の調整** — 上下左右の太さ、角の形（直角 / 丸 / 面取り / えぐり / 切り欠き）、楕円
- **自分の素材** — 画像を重ねて配置（ドラッグ移動、合成モード、枠の上だけ / 窓の中だけに描く、時間帯ごとの表示切り替え、色の塗り替え）
- **文字** — `{時間帯}` / `{英語}` の置き換え、縦書き、縁取り、フォントファイルの読み込み
- デザインのひな形 6 種、線・影・角飾り、マス目表示、元に戻す / やり直す、自動保存、プロジェクトファイルの保存と読み込み

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と CSS |
| `model.v1.js` | 初期値、時間帯、ひな形などのデータ |
| `render.v1.js` | 描画（UI に依存しない。同じ関数でプレビューと書き出しを描く） |
| `app.v1.js` | UI、履歴、自動保存（IndexedDB）、書き出し |
| `zip.v1.js` | 無圧縮 ZIP の書き出し |

座標や大きさはすべて「高さ 1080 の仮想座標」で持っているため、出力サイズを変えてもデザインの比率は崩れない。

非公式ツールであり、ココフォリアとは関係ありません。
